# Design & Aesthetic Preferences

## Kong Bootcamp Diagrams & Images

When generating images, architecture diagrams, or roadmap recaps for Kong-related projects, ALWAYS use the following aesthetic:

- **Style:** Premium dark mode, glassmorphism aesthetic
- **Accents:** Vibrant neon accents (cyan, purple, pink, etc.)
- **Lines:** Clean, minimalist lines
- **Typography:** Modern, clean typography
- **Vibe:** Sleek, professional, high-quality, customer-facing

This style is currently applied across the Kong API Gateway, AI Gateway, Agentic AI, APIOps, and Developer Portal bootcamps to ensure a cohesive, unified visual brand.
