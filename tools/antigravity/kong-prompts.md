# Antigravity Kong Prompts

## Generating Architecture Diagrams

When asked to generate architecture diagrams for Kong bootcamps, use this prompt structure:

> A sleek, professional architecture diagram for '[Topic Name]'. Visualize [Specific components and relationships]. Use a premium dark mode, glassmorphism aesthetic with vibrant neon accents, clean minimalist lines, and modern typography.

## Generating Bootcamp Recaps / Roadmaps

When asked to generate a recap roadmap, use this structure:

> A sleek, professional bootcamp recap roadmap image for 'Kong [Name] Bootcamp'. Visualize a learning journey path with [Number] sequential nodes: 1) [Module 1], 2) [Module 2], etc. Use a premium dark mode, glassmorphism aesthetic with vibrant neon accents, clean minimalist lines, and modern typography.
